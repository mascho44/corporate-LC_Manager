# Original / numbered copy designation

Documents can be explicitly marked **Original**, **Copy 1**, **Copy 2**, **Copy 3**, or left **Not designated**. This is user-entered presentation metadata, not proof of legal originality/authenticity and not an automatic count/compliance finding.

Choose the designation per file during LC batch upload, per part in split review, or while assigning an inbox document to an LC. It is displayed in the document dossier and editable with the existing document metadata editor. ZIP entries remain unspecified and can be edited individually after import. Historical documents and automatically split items remain unspecified. Generated documents likewise are not automatically declared originals.

The `copyNumber` API field is null for unspecified, 0 for original, and 1–3 for numbered copies. Both application and PostgreSQL enforce the range. Classification/split training deliberately discards this designation: a template must not label future documents original merely because one training example was.

## Stempeltext, Zahl der Originale und Full Set (Stand 17.10.2026)
* **Stempeltext als Vorschlag:** Im Posteingang wird die Kennzeichnung beim Anhängen aus dem Stempeltext **vorbelegt** (ORIGINAL → Original, COPY/KOPIE/Durchschrift/Abschrift → Copy; „Vorbelegt aus dem Stempeltext … – bitte bestätigen"). Was eine Person eingegeben hat oder der Aufteilungsvorschlag mitbringt, hat Vorrang. Gespeichert wird erst mit „Anhängen". Erkannt werden nur Stempel, die als Text auf einer kurzen Zeile stehen (OCR-tolerant, z. B. 0/O, 1/l); ein Stempel als Bild oder über Text gedruckt wird nicht erkannt. Die Nummerierung („1/3") geht verloren: es gibt nur Original und Copy.
* **Zahl der Originale im Konnossement:** Gelesen wird die Angabe auch aus der üblichen Frachtführer-Tabelle: Beschriftung „NO. OF ORIGINALS" in der Kopfzeile, darunter „3 / THREE", „THREE (3)" oder „3 (THREE)" (`StatedOriginals`). Eine nackte Ziffer unter der Beschriftung gilt nicht (Reisenummer, Container); nur Ziffer und Wort zusammen, oder die Zahl direkt hinter der Beschriftung. Widersprüchliche Angaben ergeben nichts. Dieselbe Zahl füllt als Vorschlag die Prüfdaten „Anzahl Originale".
* **Prüfung „Full Set":** Verlangt der LC ein „Full Set", wird die auf dem Konnossement gelesene Zahl mit den vorliegenden Originalen verglichen. Hat ein Dokument keine eingegebene Kennzeichnung, zählt sein Stempeltext (als „erkannt", nicht „erfasst"): „Originale: 3 erkannt / 3 gefordert … Davon 4 aus dem Stempeltext erkannt, nicht bestätigt". Bei weniger Originalen als gefordert ist das **Hinweis** statt Abweichung, solange Stempeltext beteiligt ist (der Stempel kann nur nicht gelesen worden sein); nur eingegebene Kennzeichnungen ergeben bei Fehlmenge eine Abweichung. Ein Dokument ohne Kennzeichnung und ohne Stempel hält das Ergebnis weiter unsicher. Weiterhin keine Aussage zur Echtheit.
