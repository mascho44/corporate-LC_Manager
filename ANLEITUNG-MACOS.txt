CORPORATE LC MANAGER – START AUF macOS

1. ZIP-Datei vollständig entpacken.
2. Auf „start-macos.command“ doppelklicken.
3. Das Browserfenster öffnet sich automatisch.

Voraussetzung: Java 17 oder neuer.
Download: https://adoptium.net/temurin/releases/

Falls macOS den ersten Start blockiert:

1. Rechtsklick auf „start-macos.command“.
2. „Öffnen“ auswählen.
3. Den Start bestätigen.

Alternativ im Terminal:

  cd <entpackter Ordner>
  chmod +x start-macos.command
  ./start-macos.command

Die Anwendung läuft unter:
http://localhost:8080

Zum Beenden das Terminalfenster schließen oder Ctrl+C drücken.
Die lokale Datenbank wird automatisch im Unterordner „data“ gespeichert.
